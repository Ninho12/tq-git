# 🚀 tq-git (Terminal Quizzes & Git Tutorials)

> Ferramenta CLI interativa desenvolvida em Node.js para aprender Git do básico ao avançado diretamente pelo seu terminal através de **tutoriais ricos em Markdown** e **quizzes interativos em JSON**.

---

## 📦 Instalação

### Instalação Global via NPM:
```bash
npm install -g @ninho12/tq-git
# ou no diretório local durante o desenvolvimento:
npm install -g .
```

### Execução Direta via NPX:
```bash
npx @ninho12/tq-git
```

---

## 🛠️ Comandos Disponíveis

| Comando | Descrição |
| :--- | :--- |
| `tq-git` | Abre o menu interativo inicial |
| `tq-git list` | Lista todos os 10 módulos disponíveis de aprendizado |
| `tq-git tutorial <modulo>` | Exibe o tutorial formatado no terminal (ex: `tq-git tutorial 01`) |
| `tq-git quiz <modulo>` | Inicia o quiz interativo de 5 perguntas do módulo |
| `tq-git pix` | Exibe as informações de apoio e chave PIX do desenvolvedor |
| `tq-git --help` | Exibe o painel de ajuda da CLI |

---

## 📚 Os 10 Módulos de Aprendizado

1. **`01-config-init`** — Configuração Inicial e `git init`
2. **`02-ciclo-vida`** — Ciclo de Vida dos Arquivos (`git add` e `git status`)
3. **`03-historico-commits`** — Histórico e Registros (`git log` e `git commit`)
4. **`04-branching`** — Ramificações (`git branch` e `git switch` / `checkout`)
5. **`05-merges`** — Fusão de Ramos (`git merge`)
6. **`06-conflitos`** — Resolução de Conflitos de Merge
7. **`07-remotes`** — Trabalho Remoto (`git remote`, `push`, `pull`, `fetch`)
8. **`08-desfazendo-erros`** — Desfazendo Alterações (`git reset` e `git revert`)
9. **`09-rebase-stash`** — Organização Avançada (`git stash` e `git rebase`)
10. **`10-workflows`** — Boas Práticas e Fluxos de Trabalho (Gitflow, GitHub Flow, Trunk-based)
